# Pre-Matric Scholarship (Bihar, SC/ST/OBC/Minority)

- Department: SC/ST Welfare, BC/EBC Welfare, Minority Welfare Depts (via National Scholarship Portal + state)
- Benefit: Day scholar Class 1-5 Rs 1,000/year; Class 6-8 Rs 5,000/year (hostellers higher: up to Rs 8,000/year); Class 9-10 Rs 3,500-7,000/year depending on category/hostel status.
- Eligibility: Bihar domicile; SC/ST/OBC/EBC/Minority student in Class 1-10 in a recognised school; family income up to Rs 2,50,000/year (OBC/EBC/Minority); no income ceiling for SC/ST in state top-ups but NSP central rule caps at Rs 2,50,000 for SC.
- Documents: Caste/income certificates, Aadhaar, previous marksheet, bonafide, bank account.
- Apply: scholarships.gov.in (NSP) + state MedhaSoft where routed.
- Source note: slabs indicative of 2023-25 NSP/state circulars. Verify on scholarships.gov.in.
